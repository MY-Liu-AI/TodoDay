# 目标进度甘特图：网页端市场调研与重设计

背景：「目标进度」甘特图修完刻度同轴问题后仍不够理想——刻度从今天起排导致
轴左大半没有日期、今天线顶部挂浮动标签、整体不像一个「图」。本文调研主流
网页端甘特/时间轴视图的做法，给出贴合本应用（轻量、只读、嵌入目标页）的重
设计，demo 见同目录 `goal-gantt-demo.html`。

## 市场样式调研（TeamGantt / GanttPRO / Instagantt / Asana Timeline /
Monday / ClickUp / Notion / Linear / Jira Advanced Roadmaps / 飞书项目 / Teambition）

一致做法（按出现频率排序）：

1. **时间轴铺满整个数据区间、双层刻度**。上层月份带（“2026年11月”按天
   占宽），下层日/周刻度。没有任何主流产品「只从今天起标刻度」——今天只是
   刻度上的一个高亮标记，不是刻度的起点。
2. **背景参考层**：刻度位置拉竖向网格线（recessive hairline），日粒度下
   周末/节假日列做低饱和底纹。网格线让「哪天在哪里」不需要对照刻度尺。
3. **今天 = 贯穿竖线 + 刻度尺上的小标记**（三角/胶囊贴着尺，而非悬在半空
   的浮签），线宽 1–2px、主色或红色。
4. **条形**：圆角胶囊，底槽中性色、进度用同一主色的实心填充（饱和度/明度
   区分），里程碑用菱形 ◆。分组汇总条更深色。状态色（绿/黄/红）留给
   on-track / at-risk / overdue 语义，不做装饰。
5. **标题位置**：左列表格（重型工具）或条内（轻量视图）；条内放不下时放
   条外右侧。悬停整行提亮 + tooltip 给出精确日期/进度。
6. **交互标配**：缩放（日/周/月/季）、分组折叠、拖拽改期、依赖连线。
   其中缩放与折叠对只读总览也有价值；拖拽/依赖对本场景（目标页内嵌、
   只读）明确不做。
7. 视觉基调：留白优先、网格/轴线退后（recessive）、颜色克制
   （Pageflows/Celoxis/Meegle 2025 综述一致强调）。

## 效率复核：三个问题的新结论（2026-11-11）

以「这张图帮人高效干活」为标尺，对初版 demo 三处重估：

1. **已完成事项不占行。** 进度图回答「还剩什么、什么时候、是否落后」；
   做完的事日期不再携带行动信息，且行数随时间无限累计。已完成的里程碑
   （`total>0 && done>=total`；`total=0` 视为未拆解、仍占行）折进组头
   小签「已完成 n 项」；全部完成的目标整组退出进度图（列表页与详情页
   仍有完整历史）。行数从此只跟「未完成」走。
2. **过去固定只留 7 天，更早的一律左缘虚线截断。** 今天线飘到轴中间的
   根因，是做完的旧里程碑把轴往过去撑；完成项不占行后，过去只留最近
   一周（够看上个周末），更早的不管做完没做完都不进图。逾期多久的行动
   信息是「逾期 n 天」这个数（元信息列 + tooltip，用克制的砖红状态色），
   不是看条带猜长度。截断复用开放端的虚线语义 = 「延伸到看不见的过去」。
3. **视窗 = 过去 7 天（钉死）+ 未来至少 28 天（随最远截止日延展）。**
   截止日是核心信息必须可见，未来窗不设上限；过去窗不延展。今天稳定在
   轴左侧 ~1/5 处。刻度步长沿用自适应（1/2/3/5/7/10/14/21/30 天），
   窗被远截止撑大时刻度自动变稀、标签不重叠。

## 对齐本应用后的设计决策

保留：无边框泳道、三列（标签/时间轨/元信息）、青绿单主色、开放端虚线语义、
当前步圆点、软删不动数据形状（demo 用与 WireGoal 同形的种子数据）。

从市场做法引入：

- **双层时间尺**：月份带 + 日刻度铺满当前视窗；日粒度按「好看的天数
  步长」等距取刻度（锚定轴首、间距恒定），粒度可切日/周（周模式取
  每周一）。
- **网格线 + 周末底纹**：刻度处拉 1px 竖线（周一的略深），周六日两列铺
  3–4% 透明底纹。今天线不再孤立。
- **今天 = 尺上小签 + 细线**：刻度尺下沿挂青绿小三角 +「今天 M/d」，
  竖线 1.5px、55% 透明；与尺签同位的刻度标签自动去重。
- **已完成折叠**：组头小签「已完成 n 项」，不占行、不参与定轴；
  全完成目标不进图。
- **逾期表达**：元信息列 `done/total · 逾期 n 天`（砖红状态色，全文档
  唯一状态色），tooltip 同口径。
- **行悬停提亮 + tooltip**：tooltip 显示「里程碑 · 起–止 · 完成 x/y ·
  剩余/逾期 n 天」。
- **未排期行**：时间轨里放虚线框小胶囊（中性色），不再整行留空。

明确不做：拖拽改期、依赖连线、装饰性状态色、左列折叠（本页是只读总览，
编辑在详情页）。月带中文标题沿用「专注. 任务」的中文语境。

验证：初版（满数据轴）经无头 Chrome 截图核对（浅色/深色日粒度，1440 宽）。
效率复核版（完成项折叠 + 7 天过去窗 + 逾期截断）经代码走查，修掉两个对齐
缺陷：①参考层（网格线/周末块/今天线）曾以整个绘图区宽度为百分比底，会
左偏一个标签列——改为与 app 相同的 calc 偏移钉住中间列；②「今天」尺签
宽约 64px，邻近刻度标签曾按 1.5% 固定阈值去重，窄屏下会撞上——改为按
时间轨实际像素换算阈值。截图验证被会话权限拦住未跑；demo 数据已含已完成、
逾期遗留（9/20–10/10 跨截断线）、全完成三组样例，浏览器打开即可复核。

## 移植回 app（2026-11-11）

按此设计替换线上甘特，demo 留档 design/ 供对照：

- `frontend/src/lib/goalcharts.js`：视窗轴（过去 7 天钉死 + 未来 ≥28 天
  随最远截止延展）、完成项折叠（doneCount）、月份带、日/周刻度
  （DAY_STEPS 自适应 + 周一加深）、周末底纹、clipPast/overdueDays、
  尺签 clash 抑制（按 trackPx 换算）、todayTabPos 钳制。
- `frontend/src/components/GoalsView.vue`：刻度尺 + 参考层 + 粒度切换
  （日/周，view-switch 同款分段控件）+ 组头「已完成 n 项」小签 +
  逾期元信息小签； ResizeObserver 量宽保留。
- `frontend/src/styles/planner.css`：同名类整套（.gantt-ruler/.gantt-month/
  .gantt-tick-mark/.gantt-today-tab/.gantt-weekend/.gantt-gridline/
  .gantt-done-chip/.gantt-late/.gantt-bar.clip-past）；周末底纹色挂
  画布级 --gantt-weekend（浅深两套）；逾期用既有 --neg 状态 token
  （demo 的自定义 --late 不引入）。
- `frontend/src/copy.ts`：goalChartGranDay/GranWeek/DoneChip/Overdue。
- `frontend/tests/goalcharts.test.mjs`：单测与源码契约按新口径重写。

与 demo 的两处有意差异：①无 legend（内嵌视图靠元信息列与 tooltip 自足，
不再加一排图例）；②小刻度跨度 >62 天时不画每日刻度（只留标签刻度），
避免长轴下几百根 1px 刻度的无谓 DOM。
