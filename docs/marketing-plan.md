## 一、产品形态判断：开源还是闭源？前期收不收费？

**结论：核心全量开源，前期完全免费，12 个月后靠「云服务」变现。**

### 为什么是开源

1. **品类决定功能不是壁垒。** 待办 / 日历 / 打卡是红海，闭源收费既无功能代差又无品牌，用户没有理由从滴答清单等成熟产品迁移过来。
2. **产品的差异化只有开源才讲得圆。** 真正的卖点是「数据在你自己手里 + 一个二进制文件就能跑 + AI 管道」。一个闭源的自部署工具，用户没有理由相信二进制里没有后门。
3. **现状已在 GitHub 公开运行 PR 流程**，此时转闭源付出的不是代码成本，而是信誉成本。
4. **前期收费会挡住最宝贵的种子用户**——愿意折腾 Docker 自部署的极客，恰好是开源产品第一批布道者。

### License 建议：Apache-2.0

- 最利于传播和二次集成，企业、开发者、教程博主都敢引用。
- AGPL 是防云厂商白嫖托管的；当前没有这个风险。若未来出现托管商抄袭，再评估 BSL / SSPL。
- 产品名「专注.任务」与 Logo 作为商标单独保留：**代码可分叉，不可冒名**。

### 变现路径（分阶段）

| 阶段 | 动作 | 目的 |
|---|---|---|
| 0–6 月 | 完全免费 | 唯一目标：GitHub Star、真实用户、反馈闭环 |
| 6–12 月 | 上线「云服务版」内测 | 帮不想装 Docker 的大众用户托管后端——未来订阅收入主线 |
| 12 月+ | 三层收入 | 见下 |

12 个月后的三层收入结构：

1. **云服务订阅（¥8–15 / 月）**：托管部署 +（未来）多端同步。本地自部署永久免费，作为信任状与获客漏斗。
2. **AI 额度包**：LLM 调用是真金白银的成本，AI 技能 / 助手按量付费或会员包，名正言顺。
3. **团队 / 工作区版（远期）**：多人 workspace 本来就是架构层的优势。

### 前期绝对不碰的

- 付费墙、功能阉割的「专业版」；
- 任何形式的售卖用户数据。

**原因：效率工具的信任就是产品本身，一次背刺全员逃离。**

## 二、抖音 + 小红书完整推广方案

### 2.1 两个平台的分工

| | 抖音 | 小红书 |
|---|---|---|
| 用户心智 | 刷到，3 秒决定生死 | 搜索，"值得吗 / 怎么用"的决策场 |
| 适合内容 | 动态演示、前后对比、情绪钩子 | 图文教程、清单、真实使用记录 |
| 核心人群 | 泛流量 + 学生 + 职场 | 学生、年轻职场、自我管理 / 手账圈 |
| 角色定位 | 流量放大器：一条爆款几十万播放 | **转化主战场**：搜"待办软件 / 自律 app"的人就是要换工具的人 |

**总打法：小红书做搜索占位 + 深度种草；抖音做演示爆破 + 泛流量声量。**

### 2.2 一套产品，五个卖点

不要用一个卖点打所有人。

| 人群 | 主打卖点 | 钩子画面 |
|---|---|---|
| 学生党（考研 / 期末） | 热力图 + 连续打卡 + 番茄四象限 | 复习进度被点亮成热力图 |
| 自律 / 自我管理圈（小红书主力） | 目标 → 里程碑 → 任务三层拆解、习惯打卡 | 年度目标被拆成今天要做的一件事 |
| 效率极客 / 程序员 | 本地优先、数据私有、单二进制、Go + Vue 开源 | `docker run` 一条命令起服务 |
| 极简 / 反订阅党 | 无会员、无广告、无云上传 | 「一个 exe 就是你一辈子的任务系统」 |
| 记账人群（差异化王牌） | 邮箱授权码一填，账单自动进账本 | 邮件列表 → 账本条目，全程无手输 |

> 邮箱自动记账这条内容，在小红书几乎无竞品，是现成的内容空位，优先占位。

### 2.3 账号矩阵：2 个号起步

1. **官方产品号「专注·任务 TodoDay」**：功能演示、教程、更新日志。
2. **开发者人设号（独立开发日记）**：build in public——「一个人写全栈效率工具的第 N 天」。独立开发者叙事在两个平台都是现成流量密码，且比官方号更容易起量。

### 2.4 选题库

#### 抖音（痛点钩子 + 演示）

1. 受够了待办软件的订阅费？我把自己用的开源了
2. 3 秒看清今天该干嘛：AI 四象限演示
3. 邮箱授权码填一下，账单自动记到账本
4. 一个 exe 文件 = 你一辈子的任务系统
5. 点亮热力图：连续自律 100 天的证据
6. 为什么我的待办软件连注册都不需要
7. 程序员给自己写的效率工具长什么样
8. 我为什么不推荐你继续用 XX 清单

#### 小红书（教程 + 真实记录 + 横评）

1. 2026 我用一个软件管住了目标、习惯和账单（保姆级教程）
2. 研究生自律系统搭建｜目标 → 里程碑 → 任务三层拆解
3. 免费！无广！数据存本地的待办 app 真的存在
4. 手账电子化的第 N 天：热力图打卡太上头
5. Docker 一条命令部署自己的效率系统
6. 自律 app 横评：我为什么留下了它
7. 考研 180 天打卡复盘（附软件配置）
8. 安利一个会自动记账的邮箱玩法

#### 开发者号

「第 N 天」系列、bug 修复记录、用户破千感谢帖、issue 背后的故事。

### 2.5 内容生产公式

- **抖音视频（15–40s）**：前 3 秒钩子（痛点 / 反常识 / 成果画面）→ 10–20 秒录屏演示 → 3 秒转化口播（"开源免费，评论区领"）。
- **小红书图文**：封面大字报（6–8 字痛点句）→ 图 2–6 录屏分步截图 → 尾图"怎么领取 / 怎么部署"。
- **评论区运营**：自己预埋「怎么下载」「手机能用吗」等问题并置顶回复——这是平台允许的转化入口。
- **诚实红线**：没上线的功能绝不说。多端同步 / 云备份上线前，对外口径统一为「数据只存在你自己的设备上」——在隐私叙事里这是卖点，不是短板。社区对翻车的传播是乘法式，产品侧的诚实原则在营销侧同样生效。

### 2.6 导流路径（合规设计）

平台对外链限制严格，路径必须分层：

```
短视频 / 笔记
  → 评论区 + 粉丝群
  → 公众号（同名，承接搜索）
  → 菜单栏「下载」
  → GitHub Releases / 官网下载页
  → README → Star
```

- **抖音**：粉丝群 + 合集名 + 评论区引导；简介只写公众号名，不挂链接。
- **小红书**：笔记挂「群聊」，群内发图文指引；公众号是唯一合规落点。
- **承接物**：关注自动回复 → 安装包 + Docker 命令 + 图文教程 + 用户微信群入口。

## 三、90 天冷启动执行计划

| 时间 | 动作 | 目标 |
|---|---|---|
| 第 1–2 周 | 极客社区冷启动：V2EX「分享创造」、即刻效率工具圈子、少数派、酷安、知乎"有哪些好用的待办软件" | 第一批 100 个真实用户 + 200 Star；收集好评截图作为后续内容弹药 |
| 第 3–4 周 | 双平台起号，各发 4–6 条储备内容；社区好评做成小红书「用户说」系列 | 账号权重建立，跑通内容→转化链路 |
| 第 2 月 | 固定节奏：小红书 4 篇 / 周、抖音 3 条 / 周，开发者号日更碎片；出现自然爆款后同类选题连发 3–5 条 | 跑出第一批爆款 |
| 第 3 月 | 数据复盘，ROI 最高的两个内容支柱加码；爆款投小额 DOU+ / 薯条（单条 ≤100 元，只投已验证内容） | 放大有效打法 |

**90 天里程碑**：GitHub 2k Star、双平台粉丝合计 5k、3 个满员微信群。

## 四、关键指标与复盘

- **北极星指标**：GitHub Star 周增量（真实兴趣的最诚实指标）。
- **转化漏斗**：播放 / 阅读 → 主页访问 → 公众号关注 → 下载 → 激活（建第一个目标）→ Star → 主动推荐。
- **每周看三个数**：
  1. 爆款率（>1w 播放的占比）；
  2. 搜索占位（小红书搜"待办 / 自律 / 记账"能否刷到你）；
  3. 下载转化率。

## 五、风险与红线

1. **不虚假宣传**：未实现的能力（同步 / 通知 / 上传）一律不说有；能力缺口如实呈现。
2. **合规导流**：不直接挂外链；不用"扣 1 领取"类诱导话术（会被限流）。
3. **口碑即命脉**：开源产品的口碑 = issue 响应速度。24 小时内回复；骂声就是下一条内容的素材。
